# Lenovo ThinkStation P620 profile

This is an illustrative chassis and conservative compatibility preview, not a detected inventory or Lenovo configuration approval. Ubuntu installation and live data verification are pending. No P620 connection or deployment has been attempted.

## Geometry and fit

Six PCIe 4.0 connectors are numbered top to bottom. Slots 1, 3, 4 and 5 are x16 / 75 W; 2 and 6 are open-ended x8 / 25 W. Slot 3 is the primary GPU position. This GPU planner conservatively excludes the 25 W positions until each GPU's slot-power demand is established. GPU board power alone does not establish slot-power demand.

Nominal connector offsets are 0, 20.32, 40.64, 60.96, 81.28, 101.60 mm, using the standard bracket pitch and the board diagram as a preview basis. Six bracket pitches define the modeled expansion area. These are not measurements of the user's host. Photograph anchors and generated artwork are illustrative; measure and recalibrate before treating this as a fit guarantee.

The 312 mm default length is a provisional full-length PCIe envelope, not a Lenovo-published maximum bay measurement. Drive cages, card retention, card height and power cable bends may constrain usable space. The bay input can be calibrated. MPX modules have proprietary Mac Pro connections and are rejected. NVIDIA 3090/4090 FE retain their manufacturer three-slot envelopes; the 3090 is 313 mm long.

## Power and platform compatibility

P620 has a 1000 W PSU; that is total system power, not a free GPU allowance. Lenovo's power guide supports two RTX A6000 with specified EPS12V cabling, but only one RTX 6000 Ada. Check exact board, firmware, cable FRUs, rails and cooling for every build. Mixed NVIDIA/AMD and other nonlisted combinations are not established as vendor-supported. Physically fitting a third dual-slot card does not make it a supported power configuration. Passive accelerators need directed airflow.

## Ubuntu validation after installation

1. Identify the host by SSH address; reuse one SSH ControlMaster connection.
2. Read `uname -a`, `/etc/os-release`, DMI product name, `lspci -Dnn` and `nvidia-smi -q`. Match PCI bus IDs to the physical slots; do not infer GPU numbering from slot order.
3. Inspect read-only `/sys/class/hwmon`, `sensors -j`, `/proc/meminfo`, `/proc/pressure/*` and NVML availability. CPU, GPU, DIMM, chassis fan and PSU sensors have independent support status. Missing sensors must show unavailable, not zero or a guessed reading.
4. Verify NVIDIA host driver and container GPU access before configuring the dashboard container. Inspect the existing Compose services and build a P620-specific configuration; do not run Apple SMC fan-control code on Lenovo hardware.
5. Compare host and container CPU load, RAM, GPU temperatures/utilization/power and available fans. Verify timestamps, stale-data behavior, permissions and restart persistence. PSU total power is unavailable unless a real readable source is found.

## Orientation assets

P620 assets are separate from the Mac Pro assets. The hardware is reversed horizontally so the I/O end is on the left, while brand/model text stays upright and reads left to right. Photographic families use generated P620 images; vector families reflect geometry and counter-reflect their text. The shared NVIDIA workstation base has separately rendered model lettering. This presentation does not change dimension or collision data. MPX has no P620 orientation because it cannot be installed there.
